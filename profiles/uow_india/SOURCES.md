# Sources for the UOW India knowledge base

The knowledge in `knowledge/` was compiled on **29 September 2026** from the public pages of the UOW India
website (uow.edu.au/india), as indexed by web search, including:

- https://www.uow.edu.au/india/
- https://www.uow.edu.au/india/about-uow-india/frequently-asked-questions/
- https://www.uow.edu.au/india/courses/ (study-business, study-fintech, study-computing)
- https://www.uow.edu.au/india/support/fees/
- https://www.uow.edu.au/india/support/scholarships/ (Early Bird, Merit and High Achiever, UG and PG)
- https://www.uow.edu.au/india/support/key-dates/
- https://www.uow.edu.au/india/student-life/
- https://www.uow.edu.au/india/career-outcomes/
- https://www.uow.edu.au/india/contact-us/

**Not included on purpose:**
- **Exact tuition fee amounts.** The official pages could not be read directly from the build environment,
  and third-party portals disagree with each other. The agent refers callers to the fees page or an advisor.
  To add fees, drop the official *UOW India Course Guide 2026* PDF into `knowledge/`; PDFs are indexed
  automatically.
- **Claims about Indian regulatory equivalence (UGC / IFSCA / AIU).** The agent refers these questions to the
  admissions team.

This is an unofficial proof of concept. Before real callers use it, have UOW India verify every file here.
Fees, intakes and scholarships change each year.
